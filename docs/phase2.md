📍 Phase 2: Assets & Templates
Goal: Move beyond text by adding local file storage and reusable structures.

Key Deliverables:
Image/File Support: * Create a local assets/ folder.

When an image is dropped into the editor, Tauri copies it to the local folder and stores the path in the DB.

PDF Uploads: * A "Knowledge Base" drawer to upload and store study PDFs locally.

Template System:

Create a templates table.

Allow users to "Save Page as Template" to quickly generate Study Guides or Weekly Planners.

Export/Import:

Export any page or folder as a Markdown or JSON file for backup.
