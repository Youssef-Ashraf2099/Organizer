# Nested List Examples - Test These in Your Editor!

## Example 1: Simple Nested Bullet List

Copy and paste this into your editor:

- First level item 1
  - Second level item 1.1
  - Second level item 1.2
    - Third level item 1.2.1
    - Third level item 1.2.2
  - Second level item 1.3
- First level item 2
  - Second level item 2.1
- First level item 3

## Example 2: Nested Numbered List

Copy and paste this into your editor:

1. First step
   1. Sub-step 1.1
   2. Sub-step 1.2
      1. Sub-sub-step 1.2.1
      2. Sub-sub-step 1.2.2
   3. Sub-step 1.3
2. Second step
   1. Sub-step 2.1
3. Third step

## Testing Tips

1. **Copy from ChatGPT/Gemini**: Try copying actual AI responses with lists
2. **Check Nesting**: Verify that indentation is preserved
3. **Mixed Content**: Test lists with bold, italic, and code formatting
4. **Deep Nesting**: Try lists with 4-5 levels of nesting

## What Should Work Now

✅ Bullet lists with proper nesting
✅ Numbered lists with proper nesting
✅ Mixed bullet and numbered lists
✅ Lists from HTML (AI responses)
✅ Lists from Markdown
✅ Deep nesting (multiple levels)
✅ Inline formatting within list items (**bold**, _italic_, `code`)

## Common AI Response Patterns

**ChatGPT Style:**

- Main point
  • Sub-point (note: may use different bullet characters)
  • Another sub-point
  ◦ Deep nesting

**Gemini Style:**

1. Overview
   - Detail A
   - Detail B
     - Sub-detail B.1
2. Analysis
